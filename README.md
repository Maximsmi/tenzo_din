1. Core (CubeIDE) - прошивка для микроконтроллера stm32F030 для использования с микросхемой zsc31050 преобразования и вывод изменений в тензомосте.
  
  
2. Tenzo_GUI (Python) - Пользовательский интерфейс для настройки и калибровки микросхемы zsc31050 через команды по RS-232.
   Реализовано подключение к микроконтроллеру, опрос регистров с настройками и вывод результатов в соответствующие поля приложения.
